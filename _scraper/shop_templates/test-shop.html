쇼핑몰 전체 흐름 테스트

회원가입부터 주문·토스 가결제·관리자 확인까지 직접 점검합니다.

테스트 연결을 확인하고 있습니다.

  1. 관리자 비밀번호로 테스트 모드를 여세요.
  2. 새 테스트 회원으로 가입하고 복구 코드를 저장하세요.
  3. 상품을 장바구니에 담아 배송 정보를 입력하고 주문을 접수하세요.
  4. 테스트 주문관리에서 재고·금액을 확인한 뒤 결제를 승인하세요.
  5. 내 주문으로 돌아와 토스 테스트 결제를 진행하세요.
  6. 테스트 주문관리에서 결제 상태를 확인하세요. 테스트 배송 완료 후 구매확정·적립도 점검할 수 있습니다.

테스트 모드의 회원·주문·적립금은 실제 운영 데이터와 분리됩니다. 실제 대금 청구, 상품 발송, 렌탈 예약과 세금계산서 실발급은 하지 않습니다. 토스 공식 문서용 체험 상점을 사용하며 나다운 상점 계약·실결제 개통 여부를 확인하는 테스트는 아닙니다.
