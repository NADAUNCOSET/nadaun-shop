# Mac 공급처 미러링 운영

대표 2026-10-30 지시: 모든 사이트 최소 5일 갱신, 매 업데이트 검토 HTML 갱신,
배너 원본 보존, 미확정 주 사이트는 대표 검토. Windows 렌탈 자동화는 유지합니다.

## 2026-10-30 즉시 전체 재점검 요청

5일 주기는 정기 갱신 기준입니다. 대표가 전체 재점검을 요청하면 이 기한을 기다리지 않습니다.
`full_refresh.py`가 기존 네 공급처의 private 수집을 보존하고 나머지11개 구현된 출처를
커밋된 독립 worktree에서 한 곳씩 즉시 수집합니다. 15분 정기 예약은 이 작업의 부모/자식
프로세스를 감지해 중복 수집을 시작하지 않습니다. 원본 요청은 호스트별 단일 요청·5초 간격이며
보호응답은 유지하고 자기 쇼핑몰/기프트로의 요청·리디렉션은 차단합니다.

원장은 `_private/catalog/immediate-full-refresh-20261030/queue.json`, 출처별 로그/후보/차이는
그 아래 `sources/<source>/`입니다. 이 단계는 비공개 원본 확보이며 공개 반영이나 실제 운영 검증이
아닙니다. 신규/부재/가격·옵션·분류·이미지 차이를 기록한 뒤 기존 게시 게이트로 넘깁니다.
불완전 후보와 목록 부재만으로 기존 상품을 지우지 않습니다. 현재 가우포토 초기 매칭,
그린촬영 접근 보호, 시네몰의 승인 범위 및 기프트 접근 보류는 별도로 남아 있습니다.

## 구성

- `mirror-policy.json`: 원본 기준 432000초, 900초 대기열 확인, 순차 1개 작업.
- `partner-sync-plan.json`: 공급처별 범위·주소·기한. 기존 보류는 자동 해제하지 않습니다.
- `mirror_cycle.py`: NAS 공유 host/PID 잠금, 기존 유지보수 수집 프로세스 감지,
  원본의 실제 `collected_at`/완전성 판정, 예약·성공·실패/보류 HTML과 JSON 기록.
- `mirror_runtime.py`: 인접 `nadaun-shop-auto`의 커밋된 코드로 실행합니다.
  `_private`와 수집 상태는 독립 실물이며 실행 SQLite는 기존 PC별 격리를 유지합니다.
  원본 상세 캐시는 master를 읽기 전용으로 보완합니다. 주 작업 폴더 편집은 보존합니다.
- `shop_sync.py`: 기존 전체 빌드/회귀/공급처 정책/중복/정확한 생성 목록 게시 검증을 유지하고,
  게시 전 master HEAD/index/정확한 생성 파일을 대조·백업합니다. 푸시 후 해당 파일만 SHA 대조해 동기화합니다.
- `review_refresh.py`: 게시 확인 후 master의 검토 시작 화면·09·10·11 HTML을 같은 revision으로
  갱신합니다. 기존 검토 메모를 행 ID로 보존하고 구문과 revision을 검사하며 백업을 재조회합니다.
  실패는 source 게시와 분리해 `review_html_updated=false`로 기록합니다.
- `supplier_banners.py`: 정상 공개 페이지의 관측된 최대 래스터 후보 원본을 저장하고
  SHA 중복 제거·전체 프레임 디코드·출처 원장을 만듭니다. 공개 배너 자동 승인은 하지 않습니다.

## 설치와 확인

Mac의 기존 전용 Python(`/Users/james/.venvs/nadaun-shop/bin/python`)으로 실행합니다.
새 Mac은 자신의 인증·전용 실행 환경을 설치하고 이 NAS 원본을 사용합니다.

```sh
python _scraper/mirror_cycle.py --check-only
python _scraper/install_mirror_cycle.py --enable
launchctl print gui/$(id -u)/co.nadaun.shop.mirror-cycle
```

설치 영수증은 `_private/catalog/auto-mirror/installation.json`, 로그는 같은 폴더의
`worker.stdout.log`, `worker.stderr.log`, `runs/<시각>/worker.log`입니다. Mac이 깨어 있고
NAS가 연결돼 있어야 합니다. NAS가 없으면 종료하며 로컬 대체 원본을 만들지 않습니다.
로그인 시 실행되고 15분마다 다시 확인합니다. 5일이 지난 동안 Mac이 꺼져 있었다면
다음 실행 때 처리합니다. `caffeinate -i`는 실행 중 유휴 잠자기만 막습니다.

기존 개별 장비 공급처 예약은 유지보수 중지 상태를 그대로 두고 새 단일 예약을 사용합니다.
기프트의 기존 일일 작업, 주문·결제·캘린더 예약, Windows 렌탈 작업은 변경하지 않습니다.

## 대표 검토 입구

- `검토자료/00_여기서_시작.html`: 전체 브랜드·주 기준·보조·분류·메모.
- `검토자료/14_자동미러링/00_사이트별_자동미러링.html`: 사이트별 기한·보류·실행 결과.
- `검토자료/13_공급처배너/00_전체배너_검토.html`: 배너 후보 원본과 출처·검토 상태.
- `검토자료/12_전체미러링점검/00_전체미러링_현재상태.html`: 전수 최신 대조의 잔여 조건.

펀노마드는 검토된 51개 제품/제품군 범위이며 제조사 전체 SKU가 아닙니다.
메뉴나 이미지 동일성이 변하면 검토가 필요합니다. 모션나인은 원본 옵션코드/라벨/가격과
Product/ProductGroup 스키마를 대조하며 원본 가격에 공용 투영 단계에서만 5%를 더합니다.
가우포토 Godox 포토·그린촬영 NiSi의 초기 수집/매칭이 미검증인 동안은 어댑터 대기로 표시합니다.

## 장애 처리

수집 실패/빈 응답/불완전 목록으로 기존 상품을 삭제하지 않습니다. 접근 보호 응답의
래치를 자동으로 해제하거나 다른 경로로 재시도하지 않습니다. 외국 호스트의 NAS 잠금은
빼앗지 않고, 같은 Mac의 종료된 부모/자식 PID만 확인해 종료된 lease를 복구합니다.
자동 worktree에 미완료 생성 파일이 남거나 master의 정책/생성 파일이 바뀌면 자동 게시가
기다립니다. 해당 영수증과 diff를 확인해 백업·내용 검토 후 처리하며 `reset --hard`로 정리하지 않습니다.

예약 등록, 원본 수집, 게시/실제 원본 ID 대조, HTML 갱신, 전체 최신 미러링, 로그인/결제와
브라우저 UI 검수는 각각 별도 상태입니다. Vercel READY만으로 전수 미러링 완료를 표시하지 않습니다.
