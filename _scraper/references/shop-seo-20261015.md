## 공식 검색 가이드

2026-10-15 확인. 브랜드와 서비스에 맞는 고유 제목/설명, 읽을 수 있는 본문과 연결을 중심으로 적용한다.

- [Google SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide): 방문자에게 유용한 콘텐츠, 구체적인 제목과 설명, 탐색 링크와 sitemap. 노출이나 순위의 자동 보장은 없다.
- [Google LocalBusiness structured data](https://developers.google.com/search/docs/appearance/structured-data/local-business): 실제 업체 주소·전화·영업시간을 구조화하고 배포 후 Rich Results/URL Inspection에서 확인한다.
- [Google Site names](https://developers.google.com/search/docs/appearance/site-names): 홈 페이지 WebSite 이름과 대체 이름으로 사이트 정체성을 제공한다.
- [Google 지원 메타 태그](https://developers.google.com/search/docs/crawling-indexing/special-tags): `meta keywords`는 Google 색인/순위에 사용되지 않는다. 키워드 나열용 태그를 추가하지 않았다.
- [네이버 SEO 기본 가이드](https://searchadvisor.naver.com/guide/seo-help): 페이지 주제를 나타내는 고유 제목/설명과 이해 가능한 마크업을 사용한다.
- [네이버 콘텐츠 작성 권장](https://searchadvisor.naver.com/guide/content-basic): 브랜드와 관련 없는 인기 키워드 삽입은 피한다.
- [네이버 검색어 트렌드 API](https://developers.naver.com/docs/serviceapi/datalab/search/search.md): 제공값은 기간 내 최대값을 100으로 놓은 **상대비율**이며 절대 검색량이 아니다. 이번 작업에서 API를 호출하거나 검색량 순위를 확정하지 않았다.
