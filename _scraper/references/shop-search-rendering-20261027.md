# 2026-10-27 검색 수집 개선

## 문제와 변경

`catalog.html?kind=rental`과 종류·브랜드 필터가 있는 목록은 첫 HTML에 기본 구매 상품이 들어 있고 JavaScript 실행 후 바뀌었다. 기존 검색 함수 안에서 브라우저의 `catalogSelection`과 정렬 규칙을 공유하여 요청한 상품 24개, 페이지 이동 링크, 제목·canonical·CollectionPage 구조화 데이터를 서버에서 출력한다. 없는 브랜드·종류·페이지는 404, 자유 검색·정렬은 noindex다. 상품·가격 원장은 변경하지 않는다. 함수 수는 기존 12개를 유지한다.

사이트맵은 정적 HTML의 자기 canonical과 robots를 읽어 공개 메뉴를 자동 발견한다. 기존 상품·브랜드 URL과 중복 제거하며 image:loc를 페이지 수로 세지 않는다. 다음 공개 메뉴도 전체 카탈로그를 재수집하지 않고 `write_sitemaps`로 반영할 수 있다. 장비 URL이 50,000개를 넘으면 분할 준비 전 출판을 중단한다.

## 검증과 운영 경계

새 Node 4건, Python 2건과 기존 SEO Python 11건 통과. 선택한 Node 회귀검사 52건, 최종 메타데이터 변경 후 관련 19건 통과. 카탈로그 릴리스 검사는 revision `28196ebf7b294b86`, 상품 30,149개, 검증 대상 500파일 일치다. 로그·백업은 NAS `_private/seo/google-20261027/`에 보존한다.

Search Console에는 사이트맵 5개와 주요 HTML 4개의 색인 요청을 실제 제출했다. 2026-10-27 확인 시 catalog/gift-1/gift-2/gift-index 4개는 성공이고 루트 index는 가져오기 오류가 남아 있다. 루트 XML은 공개 HTTP와 Google 실시간 검사에서 200·XML·수집 성공이 확인되어 XML 문법 오류를 원인으로 단정하지 않는다. 제출 접수, 사이트맵 처리 성공, 실제 색인은 각각 따로 기록한다.

AI 검색을 위해 별도 파일이나 확인되지 않은 인기 키워드를 만들지 않는다. 공개 텍스트, 의미 있는 제목, 제품 규격, 서버 HTML과 실제 링크를 개선한다. Google 색인·AI 노출·애드센스 승인은 보장하지 않는다.
